# 建模进展与验收口径

截至 2026-11-24。最初目标是让现有 UG/NX 通过 MCP 接受建模要求，生成可编辑的特征、参数、零件和装配，并用 NX 自身测量、独立几何判定和保存重开检查验证结果。实验由通用零件、运动机构、曲面和 STEP 回读，延伸至已有网格的导入与收藏模型的静态外观、数字装配核验。

环境为 Windows 11 x64、Siemens NX 12.0.2.9、Python 3.12。主链路为 MCP stdio → Python 适配器 → Windows 本地命名管道 → 在 NX 主线程执行的 NXOpen .NET Loader。另有由 NX Journal 入口直接运行的 VB.NET 案例。两条路径均保留原生验收证据，归档证据注明具体入口。

## 已完成的工作

- **通用 CAD 和机构。** 建立草图、拉伸、孔、参数编辑、装配约束、测量与导出链路。为四连杆、凸轮、行星、Delta 等用例分别记录求解、离散位置和交换文件回读。高级空间曲面、修剪与有界几何另外保留未知项。[原生结果索引](../outputs/README.md) · [源码案例](../src/nx-ai-lab/bridge/PHASE_EXAMPLES.md)
- **任务执行和几何判定。** 保留 TaskStore、MutationDomain、Worker、阶段 MCP、原生回执适配、几何积分与修剪判定源码。离线历史裁决分别绑定任务、操作、原始证据和签发状态。A 的历史修复与原始失败分开；真实 B 的获批正文原件缺失，联合正式核验结论为 `MATERIAL_INCOMPLETE`。
- **外观与装配。** 从单件网格导入、通用参数化展台，进展到 12 文件的同目录 NX 数字总装。R8-B 确认灰柄和棕色块一体、其余固定。R9 三态均为 44 对分离、9 对接触、2 对固定件相交；活动展示组无正体积穿透。5 个机位覆盖了这三个姿态。[R9 三态统计](../outputs/records/r11-r9-pair-summary.json)
- **打印准备。** 七件与历史切片来源字节一致，所选工况小计 1,998.50 g、34 小时 04 分 22 秒；另四件未绑定当前几何的切片结果。整机工时、总耗材、实物强度和寿命均未验证。
